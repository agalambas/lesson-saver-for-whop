# Lesson Saver for Whop 1.2.0

Independent Chrome side-panel extension. Scan your currently open Whop lesson, select its detected videos, add them to your list, and choose Download all. Open each additional lesson and scan it to add more.

Load this folder using chrome://extensions → Developer mode → Load unpacked. If updating an installed copy, click Reload there first. Keep the side panel open while downloading. Files save in Downloads/Whop Videos.

Signed links are kept only in browser-session memory. Your list remains on the device, but unfinished videos need rescanning after restarting Chrome or updating the extension. Remove deletes a list entry; Clear completed removes finished entries. Neither deletes saved video files.

Separate audio/video streams are combined into MP4 locally. Already combined MPEG-TS streams save as TS. Streaming downloads have a 1 GB limit and processing needs additional memory. DRM/encryption, live streams, byte-range streams, and changing initialization data are unsupported.

Download only media you own or have permission to download. No affiliation with Whop or Mux.
